# Results Folder

This folder stores all outputs produced by the pipeline:

## Key Files
- `k_selection_elbow.png` : SSE/Inertia elbow curve  
- `k_selection_dendrogram.png` : Ward hierarchical dendrogram (supports k choice)  
- `cluster_plots/` : dominant clusters and refined subclusters  
- `subcluster_analysis/` : centroid-distance based subtype reassignment  
- `gene_rankings/` : top-genes per cancer type from Logistic/Tree/PCA  

All results are regenerated by running:

```bash
./run_all.sh
