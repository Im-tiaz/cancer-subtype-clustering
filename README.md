# Cancer Subtype Clustering (TCGA RNA-seq)
This repository contains the full machine learning pipeline used in the paper  
**"Machine Learning Modeling for Identifying Cancer Subtypes from Gene Expressions"**.

## Contents
- Raw & processed data folders  
- Scripts for k-selection, clustering, recursive subclustering  
- Feature importance ranking  
- Jupyter notebooks mirroring the scripts  
- Results placeholders  
- Full instructions for reproduction  

## How to Run
1. Create `conda` environment  
2. Run preprocessing  
3. Run k-selection (elbow + hierarchical dendrogram)  
4. Run main clustering  
5. Run recursive refinement  
6. Run subtype-distance analysis  
7. Run gene importance ranking
